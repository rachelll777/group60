【编译方法】

方法1: 使用 Dev-C++ (最简单)
----------------------------
1. 打开 Dev-C++
2. 文件 → 新建 → 项目 → Console Application (C++)
3. 项目 → 添加到项目 → 依次添加：
   - main.cpp
   - end1.cpp
   - saveprogress.cpp
   - player.cpp
4. 按 F9 键编译并运行

方法2: 使用CMD命令行 (推荐)
----------------------------
步骤1 - 打开CMD：
  - 按 Win+R，输入 cmd，按回车
  - 或在文件夹地址栏输入 cmd 按回车

步骤2 - 进入项目目录：
  cd /d d:\AAAdelivery_game

步骤3 - 编译（选择一种）：
  方式A: make
  方式B: g++ -std=c++11 -Wall -Wextra -O2 -o delivery_game.exe main.cpp end1.cpp saveprogress.cpp player.cpp

步骤4 - 运行游戏：
  delivery_game.exe

如果提示 "g++ 不是内部或外部命令"：
  请使用方法1 (Dev-C++) 编译

完整示例：
  cd /d d:\AAAdelivery_game
  dir                    (查看文件)
  make                   (编译)
  delivery_game.exe      (运行)


【游戏操作】

主菜单:
-------
直接输入数字选择：
  1 - 查看游戏说明
  2 - 简单模式（小地图，2个包裹）
  3 - 困难模式（大地图，5个包裹）
  4 - 继续游戏
  Q - 退出

游戏中:
-------
移动: W(上) A(左) S(下) D(右) + 回车
保存: V
退出: Q

地图符号:
-------
P  = 你的位置
#  = 墙壁
1,2,3... = 包裹
C  = 客户

游戏目标:
-------
在限定步数内，收集所有包裹并送到客户(C)处


【常见问题】

Q: 编译时提示"Permission denied"?
A: 关闭正在运行的游戏程序，或使用命令：
   taskkill /F /IM AAAdelivery_game.exe

Q: 菜单选择没反应?
A: 输入数字后记得按回车键

Q: 如何保存游戏?
A: 游戏中按 V 键，会保存到 game_save.txt

Q: 如何加载存档?
A: 主菜单选择 4 (Continue Game)


【游戏技巧】

1. 先观察地图，规划最短路线
2. 一次性收集多个包裹再送货
3. 注意剩余步数，合理安排路线
4. 善用保存功能
